A deterministic, stdlib-only Python program that writes one sentence (135 characters) — the excuse a house cat gives in the five seconds after knocking a glass off the table — to `/output/entry.txt`, for make.fun's "Five Seconds to Explain the Glass" bounty. The glass parked itself on the cat's zoomies runway right before the 3am sprint, so the cat cleared the track, as any athlete in the house would do. No apology, no confession, just the cat's case.

## Run it

```sh
python3 main.py
```
